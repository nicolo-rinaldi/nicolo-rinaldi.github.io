# nicolo-rinaldi.github.io

Personal website, built by GitHub Pages with Jekyll. Live at https://nicolo-rinaldi.github.io

| What | Where |
|---|---|
| Name, tagline, social links, CV | `_config.yml` |
| Bio (home page) | `index.md` |
| Blog links (Sease articles) | `_data/blog.yml` |
| Contributions | `_data/contributions.yml` |
| Style | `assets/css/main.css` |

Push to `main` and GitHub rebuilds the site in about a minute.
